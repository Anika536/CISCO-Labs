Project summary : This is the final capstone project that I did during the completion of Networking Fundamentals course offered
by Akamai.

I tried to visualize the Networking of an wired IT company. I have practically applied the knowledge that I gained during my 
completion of the course.

Devices I've used : Routers, switches, end devices such as servers and PCs.

Networking concept : The networking concept that I used here is implementing a secured LAN network for the SOHO clients. 
The IP addressing is done using DHCP system. 
I've implemented the concept of DMZ while configuring the web server and the ISP is part of WAN whereas the employees of the 
IT farm are part of the LAN. The web server works for all of the employee PCs and all of the PCs can ping each other, 
making the network configuration a completely functional network structure.
